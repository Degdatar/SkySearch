SkySearch · Complete Mod Guide

Find records in your Skyrim session

Search loaded Skyrim records by category, name, or FormID, then run supported actions such as teleporting, tracking, and spawning.

Search and result limitsOpen section

Search and result limits

Select one or more categories before searching. Search by name or FormID. Leave the query empty and press Search to browse records in the selected categories. The configured maximum results applies to typed and blank searches. Numeric settings show their minimum and maximum below each field: results 1–5000, inventory count 1–2140000000, and world spawn count 1–100.

To see a particular record type, select its category. Mod browsing can narrow results to records belonging to a selected loaded plugin.

Available actionsOpen section

Available actions

Depending on the selected record, SkySearch can add eligible items, spawn supported objects, learn spells/shouts/perks, manage quest state, or teleport to actors and cells. Teleport actions close SkyOS so play resumes immediately.

For mod creatorsOpen section

For mod creators

SkySearch settings live in SkyViewer. The SkyOS Modder Starter Kit is for publishing integrations or companion modules; it is not required for players using SkySearch.

Speed tipsOpen section

Speed tips

Choose only the categories you need and use a modest result cap for blank searches. The search is limited to records loaded in the current game session.

SkySearch · Mod information and player requirements

Search workflow

Run a focused search

  1. Select one or more record categories.
  2. Enter a name or FormID and search, or leave the query blank to browse the selected categories.
  3. Use the plugin filter to focus on a loaded mod when that filter is available.
  4. Select a result to inspect it and choose an action supported for that record type.

Loaded-session records

SkySearch searches records loaded by the current Skyrim session. It does not download a full mod database or maintain its own saved index. A record from an inactive or unloaded plugin will not appear.

Troubleshooting

No results

Check the selected categories, plugin filter, spelling, and FormID format. Clear the plugin filter or raise the result cap when browsing a broad category.

Settings do not appear

Open SkyViewer → Modules → SkySearch. Numeric values can be typed within the minimum and maximum shown under each field. Reopen SkyOS after installing a new module package.
